### [Blog 1 - Building Complex RAG Systems: When to Custom Build, When to Use Amazon Bedrock?](3.1-Blog1/)
An architectural evaluation comparing Fully Managed RAG (Knowledge Bases for Amazon Bedrock) versus custom-built RAG pipelines. The article explores technical trade-offs regarding deployment speed, custom OCR/chunking flexibility, multi-tenancy access control, and operational cost optimization.

### [Blog 2 - [AWS Architecture] LearnSphere System Architecture Analysis](3.2-Blog2/)
A detailed architectural breakdown of LearnSphere's backend and frontend systems on AWS. The design combines Serverless Static Hosting (S3 + CloudFront), Containerized Backend (EC2 + ECR), automated CI/CD via GitHub Actions, CloudWatch monitoring, and integration with external APIs (OpenAI API, MongoDB Atlas).

### [Blog 3 - [AWS Security & Network] Network Segmentation & Infrastructure Security Analysis for AI Learning Platform](3.3-Blog3/)
An in-depth security and networking analysis covering VPC design (Public/Private Subnets in Singapore Region), dual S3 bucket isolation (Static Frontend vs Media), secure outbound traffic controls (SSM Parameter Store, MongoDB Atlas IP Whitelisting), CloudWatch alarms, and future security upgrades with ALB & AWS WAF.
